# route3d_topology_editor

用于在 RViz 内加载、查看和编辑 Route3D Topology Schema V2 JSON。

## 使用

```bash
./sh/19_edit_topology.sh
```

在 `Topology Editor` 面板中选择“顶点”或“边”，再选择 `V编号`/`E编号`。
也可在 RViz 工具栏选择“选择拓扑”（快捷键 `S`），然后直接点击图上的点或边。
修改属性后点击“应用修改”，确认显示效果后点击“保存”。保存时先把原文件复制为
`topoGraph_data.json.bak`，再通过临时文件原子替换原文件。

面板顶部提供两个全范围快捷按钮：

- “全图停障（0 + PID）”：把所有边设为 `obstacleMode=0`、`controllerMode=pid`。
- “全图避障（1 + Efficient 3D）”：把所有边设为 `obstacleMode=1`、
  `controllerMode=efficient_3d_local_planner`。

两个按钮都会先显示确认框，只修改内存并支持一次撤销；仍需点击“保存”才写回 JSON。

## 添加、连接、移动和删除

- 添加点：点击“添加点”，按 `S` 激活“选择拓扑”工具，然后在 RViz 中点击位置。
  可以连续添加；新点使用自动记点的默认属性。
- 添加边：点击“连接两点”，按 `S`，再依次点击两个已有顶点。新边默认
  `obstacleMode=0`、`controllerMode=auto`、双向、线速度 `1.0 m/s`。
- 移动点：先选中顶点，点击“移动当前点”，再点击新的 XY 位置。原 Z 高度保持不变，
  相邻边长度会自动重算；Z 可以继续在属性表单中修改。
- 删除点：点击“删除选中点及关联边”，确认后会同时删除该点连接的全部边。
- 删除边：选中边后点击“删除选中边”。

所有结构修改都先保存在内存中、支持撤销；点击“保存”后才会写入 JSON。

## 批量编辑一段路径

1. 勾选“批量点选起点/终点”，在工具栏选择“选择拓扑”（快捷键 `S`）。
2. 依次点击两个顶点。编辑器按边长度计算两点间的最短拓扑路径；绿色球是起点，
   红色球是终点，黄色点线是将要批量处理的范围。
3. 在“批量字段”中选择要修改的单个字段，设置表单值后点击“批量应用”。这样只覆盖
   指定属性，不会误改其他值；也可明确选择“全部可批量属性”。
4. “顶点”页可修改路径内全部顶点的非几何属性。为防止地图损坏，批量操作不会修改
   顶点 XYZ、RPY 或 PCD。“边”页可修改路径内全部边的控制、方向、速度和避障属性。
   每次批量操作只产生一条撤销记录，保存前仍可撤销。

也可以先选中顶点，再用“当前点=起点”和“当前点=终点”两个按钮确定范围。

不要在 `18_start_live_odom_waypoint.sh` 仍在记录时编辑同一个文件，否则记录节点的定时
快照会覆盖尚未保存或刚保存的编辑。
